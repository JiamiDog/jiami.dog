# 无 SSN 新手美卡入门指南

> 本文同步自 [jiami.dog 官方原文](https://jiami.dog/4478.html)，以官网版本为准。

![一张蓝色的卡通风格信用卡，卡面印有“No Name BANK”字样和红色的银行标志。](https://jiami.dog/wp-content/uploads/2023/01/1672829335-20230104184841.png)

### 一、关于 SSN

SSN 即美国**社会保障号码**（英语：Social Security number）是美国联邦政府**社会保障局**（英语：United States Social Security Administration，缩写：SSA）发给本国公民、永久居民、临时（工作）居民的一组九位数字号码。社保号码主要的目的是为了追踪个人的赋税资料，但近年来已经成为实际上的身份证。（Wikipedia）

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2023/01/1672829102-20230104184338.png?resize=679%2C416&ssl=1)

SSN 由九个数字组成的号码，首位数字为 1-8，格式为“AAA-GG-SSSS”。SSN 由 SSA 发放

“~~911 之前甚至来美国旅游的游客，都可以轻易地申请到 SSN~~”，之后美国国土安全部（DHS）建立了美国访客与移民身份显示系统，对 SSN 的发放制定了严格的要求与申请程序，留学生必须要工作才能获得该号码。

### 二、关于 EIN

EIN 即**雇主身份号码**（英语：Employer Identification Number）又称联邦税识别号码（Federal Tax Identification Number），用来识别企业实体。（IRS）

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2023/01/1672829147-20230104184411.png?resize=768%2C1021&ssl=1)

EIN 由九个数字组成的号码，格式是：xx-xxxxxxx。EIN 由 IRS 发放

### 三、关于 ITIN

ITIN 即美国**个人纳税识别号码**（英语：Individual Taxpayer Identification Number）是由**美国国家税务局**（英语：Internal Revenue Service，缩写：IRS）发放的美国税务处理号码。它是一个首位为数字 9 的九位数（Wikipedia）

美国国税局向个人签发 ITIN 的目的是帮助他们遵从美国税法的规定，同时使没有资格从社会安全局 (SSA) 取得社会安全号码 (SSN)者的报税表和缴纳的税金能够获得有效率的处理与记录。**获取 ITIN 不受移民身份影响，无论是税法定义居民 (RA) 或非居民外国人 (NRA)** 。ITIN 不得用于申报联邦税外的其他用途，不得用于在美国进行工作等。（IRS）

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2023/01/1672829240-20230104184428.png?resize=748%2C1024&ssl=1)

ITIN 由九个数字组成的号码，首位数字为 9，格式是：9xx-xx-xxxx。ITIN 由 IRS 发放

随着 ITIN 的普及，一些美国银行自愿接受 ITIN 做为 SSN 的代替文件，以批准没有 SSN 的人申请银行账户和[信用卡](https://jiami.dog/tag/credit-card "信用卡")，同时可能还需要额外提供身份证明（比如护照驾照）、收入证明（比如工资单税表）、地址证明（比如水电账单）等文件。

```
• ITIN 有效期 5 年，可提交护照 + W-7 续期
• 连续三年未报税的 ITIN 也会过期
• 一旦指定個人納稅識別號碼後，它將屬於那個報稅人，除非遭到撤銷。更新個人納稅識別號碼時，將會更新先前指定的號碼（IRS faqs A24）
```

## 四、美卡入门有哪些方式 #**Guide**

### 1. 通过不需要信用记录的银行申请首卡建立信用记录 #Checking

```
土豪和留学生首选
```

- **BofA：**无信用记录只能通过线下网点申请 Checking 账户，存入 $3000 以上，即可找开户经理或者直接电话申请信用卡。
- **Deserve EDU：**这是一张专门针对学生设计的信用卡，国际学生无需 SSN、无需信用记录即可办理。要求提供学校和专业、护照、签证、I-20 或 DS-2019、银行账户信息等（美卡指南）
- **HSBC USA：**持有其它地区 HSBC Premier 账户的用户，通过 RM 或者直接网申 [HSBC USA Premier 账户](https://jiami.dog/4710.html)后，可同时申请 HSBC 信用卡。

### 2. 通过持有其它地区的 AmEx 信用卡 GT 到美国 #Global Transfer

```
Amex 即是裁判也是选手，有很多神奇的操作，而且申请审批也比较容易
```

1）**GT 有两种：**

- 第一种是登录现在国家/地区的 AmEx 账户后，通过菜单上的 切换国家/地区来申请。
- 第二种是与第三方供应商 Nova Credit 合作，美国运通可以访问你在澳大利亚、巴西、加拿大、多米尼加共和国、印度、肯尼亚、墨西哥、尼日利亚或英国的信用记录来申请。需要在申请信用卡的页面上勾选 “*I don’t have a credit history in the US, but*…”

2）**GT 的要求：**

- **现有的卡必须是由美国运通发行的**，必须是主卡，并且已经持有该卡至少3个月。卡必须是有效的，并且信用良好。（AmEx US）
- 可能会要求提供额外的资料，比如护照、地址证明、银行账单证明等。

3）**GT 的建议**：

- 如果目前不持有任何国家/地区的美国运通账户，可通过先申请德国的 N26 银行账户 并使用1-3个月后，申请 德国 AmEx 信用卡。信用卡使用 3个月后，再 GT 到美国。
- GT 新卡的额度一般会参考目前持有卡的额度，Member Since 也可能会继承。

### 3. 通过押金卡建立信用记录 #Secured Card

```
押金卡字如其名，一般来说，押多少资金额度即有多少，押太少影响后期申请主卡额度
```

- **BofA：**接上面，如果通过持有 Checking 账户申请普通信用卡失败，可以先申请押金卡。
- **Capital One：**需要有 ITIN，可以无信用记录直接在官网申请
- **~~Sable~~：**基本上已经死了，关闭了很多现有用户，也不接受新用户申请。
- **Velo：**华美旗下的 Velo 也提供押金卡，而且 Velo 的银行账户用大陆身份证就可以开户。

### 4. 通过副卡建立信用记录 #Additional Card

```
副卡会占用副卡持有人信用报告上的账户数，影响诸如 5/24 等银行规则
```

- **AmEx：**副卡建立信用记录使用最多的大概就是 AmEx 副卡了。AmEx 副卡和主卡区分开，有自己独立的卡号信息，可以建立副卡网银账户，是通过副卡建立信用记录的首选银行。持有 AmEx 副卡 3 个月后，即可自主电话申请主卡。
- **~~Apple Card~~**：注意 Apple Card 副卡如果要建立信用记录只能绑定 SSN 且不支持 ITIN，未绑定 SSN 的副卡不会上报信用记录。
- **Capital One：**C1 副卡持有人同样可以注册自己的网银账户。
- **Chase：**Chase 副卡追溯主卡的信用历史长度，但由于副卡和主卡拥有同样的卡号信息，会有诸多不便。

### 5. 通过第三方机构建立信用记录 #credit-build

```
不推荐
```

- **Self.inc**：这是一种 **Credit-builder loan**，提供 1-2 年期最低每月 $25 的贷款并向信用局报告来帮助你建立信用，申请需要 SSN/ITIN
