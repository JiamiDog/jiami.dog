## **Fiverr 平台工作原理**

如果你擅长设计Logos，网站建设或视频制作。或者，你可以通过其社交媒体或人力资源策略帮助企业。无论你的天赋如何，Fiverr都使你有机会与其他在线世界分享这些技能。最重要的是，你可以在做自己喜欢的事情的同时赚钱。

### **Fiverr 平台上有两种角色：**

| **卖方Sellers** | **如果你是找工作的自由职业者，那么你将被Fiverr视为“卖方”。卖方可以列出他们想要的任何类型的服务，以及他们希望获得的费用。你被雇用的机会取决于你的行业经验和你在Fiverr的经验。** |
| --- | --- |
| **买家Buyers** | **如果你想购买服务，则你就是“买家”。买方寻求帮助需要完成一些任务，无论是特定的任务，工作还是项目。他们可以是企业，公司，甚至是个人。在Fiverr上，买方雇用卖方以帮助他们完成这项工作。** |
| **这个其实很好理解，如果你是想赚钱，那么就把你擅长的卖出去，自然就是卖方了。如果你想找人帮忙设计logo或者网页的话，需要花钱买别人的产品，自然就是买家。** | |

Fiverr是一个双向交流平台，这意味着买卖双方都有机会互相寻找。买方可以浏览自由职业者的介绍，找到符合他们要求的卖方。或者，卖方可以浏览买方的要求，以找到与其技能相匹配的任务。

买卖双方找到彼此后，他们将就设定的目标，时间表和价格达成一致。接下来卖方需按照买方的要求去完成任务，然后得到自己的报酬。

## **Fiverr 任务价格**

在Fiverr上，所有的服务都被称为Gig，其中很多起步价格仅为5美元，但是这只是最低工资，事实上，很多任务的薪酬与其他全职招聘网站相同（甚至更高）。但是价格也是有上限的。普通的Fiverr产品最高不可以超过995美金，除非你是加入了[**Fiverr Pro**](https://fvrr.co/3HdJwNo)，这样价格可以放超过995美金以上。

但是**Fiverr Pro**并没有这么容易就申请到，你还需要经过各种测试，考试，并且还需要通过认证。当然，Fiverr Pro是定位在价格高，服务更加专业的客户体。如果你是新手，或者想赚外快的，基本上注册Fiverr普通会员就行了。

## **[Fiverr 收取的费用](https://jiami.dog/4188.html)**

Fiverr基本上是属于免费的平台，意思就是说你可以在上面免费卖你的任何服务。但是你在Fiverr上卖的所有服务，它都会收取佣金，永久是20%，这是唯一的费用。

也就是说，当你卖出了5块的服务，Fiverr会收取1块，你获得4块。如果100美金，Fiverr收取20美金，你获得80美金。其实费用还是算蛮高的，所以在定价的部分，可以把这个费用考量进去。尤其是当你在做高价格服务的时候。

## **Fiverr 使用教程**

### **第一步：注册Fiverr帐号**

想要利用[**Fiverr 平台**](https://fvrr.co/3lL7OqI)赚钱，就必须先注册一个卖家帐号，可以用Google 信箱、Apple账号或是Facebook 帐号注册。注册完成后会收到验证信，到信箱收信即可。

进入[**Fiverr**](https://fvrr.co/3lL7OqI)网站之后，点击右上角的“Become a Seller”或者“Join”，

![image.png](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/06875f39b13354a760d178867302766a.png?ssl=1 "1645598523231727.png")

即可到达注册页面。

![image.png](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/ccfecac07dc04eb4d1bc3ba47631a487.png?ssl=1 "1645598549872660.png")

### **第二步：完善个人资料**

注册都是非常简单，按照提示把所有信息都填完整就可以了，提交之后你会收到一封确认邮件，确保是邮件本人注册的，你邮件确认完毕后就可以开始**完善自己的资料**了。对于自由职业者来说，个人资料是非常重要的，买家会认真看你的资料看是否匹配完成任务的能力，因此，要认真对待完善自己的个人资料，这是你的第一门面，将自己最突出的技能展现出来。

### **第三步：建立Gig**

现在你已经拥有一份描述性资料 ,接下来需要创建Gig与潜在买家分享，你需要提供关于服务、要求、收费等信息。请将Gig视为你的工作描述，因为在阅读完个人资料后，潜在买家会浏览它们，看看你是否适合他们的项目。

**每个Gig都要求你填写关于你的服务的基本信息，包括：**

**1. 概述**

当你点击 “create a new gig”，你需要填写的第一个部分是概述（Overview）。你需要为以下部分提供信息。

| 1. Gig名称：告诉你的潜在买家你能提供什么。 |
| --- |
| 2. 类别：选择一个适合你所提供的服务的类别和子类别。 |
| 3. 服务类型：选择你想为买家提供的服务。 |
| 4. Gig元数据：选择能使你的Gig脱颖而出的选项。 |
| 5. 搜索标签：选择能够帮助你的Gig在买家搜索服务时排名靠前的关键词。 |

**2. 定价**

Fiverr使用套餐作为平台上销售服务的定价结构。套餐让卖家将基本的服务与内置的修改和其他额外的服务结合起来，创造出一个能让买家满意的报价。

**套餐的定价方式通常是这样的：**

| - 在 “为你的套餐命名” 字段中，给该部分一个标题。如果你选择使用三个部分，给每个部分起一个独特的名字。 |
| --- |
| - 描述你将向买家提供的服务，并选择交付时间。交付时间应该是恒定的或按升序排列。 |
| - 选择你能提供给买家的修改次数，以及每一部分的总价格，以升序排列。 |
| - 你可以选择包括额外的服务或完全省略。 |

**3. 描述和常见问题**

在描述部分，以最好的方式解释你的Gig意味着什么。通过回答你认为买家可能想知道的关于你提供的服务的问题，来填写常见问题的区域。

**4. 要求**

在要求这一部分，填写你希望买家在你开始项目之前提供什么。

**5. 图库**

你可以在这里添加与你所创造的Gig有共鸣的图片或视频。你还可以下载免费的图片库或创建一个视频来宣传你的Gig。

**6. 发布**

当你完成了所有Gig信息的填写，并且你确定它看起来不错，点击 “发布”。一旦你这样做，Gig就会生效发布，买家就能找到它。

**温馨提示**

| **与被动等待买家相比，主动出击可以让你获得更多的工作机会。有些买家会发布服务请求，列出他们需要完成的工作或任务技能要求、截止期限、愿意支付的报酬等信息。作为卖方，你可以浏览这些请求，然后将报价直接发送给买方。** |

## **实用小技巧**

### **1. 关于简历投递**

关于Send offer，可以写好一个简历保存起来，方便有buyer request的时候使用。简历撰写方法：和客户问好，突出自己的优势（速度快，价格低，服务优），只是在Fiverr这个平台上是新手，希望可以给自己一个机会，对于大单，可以向客户说明自己拥有强大的翻译团队。

### **2. 关于Promote My Gigs**

建议在QQ或者微信上加一些不是很重要的群，比如副业兼职群，聊天群……去里面发布，提高点击量。小技巧执行起来后，真的有助于度过瓶颈期。

### **3. 接单问题**

有时会遇到没有字幕的视频单子，翻译难度较大，建议和客户沟通，寻得更多信息来降低翻译难度，可以问问客户有没有文本之类的。对于自己难以拿下的单子，建议和其他小伙伴合作，把单子接下来，积累好评。

### **4. 身份验证问题**

身份验证时，不要上传手机里面保存的照片，建议选择光线好的地方进行现场拍摄，保证清晰度来提高通过率。

### **5. 客户回访很重要**

建议隔一段时间和客户问好，问问需不需要帮助，这样会极大地提高复购率。拥有回头客，在带来收益的同时也会吸引更多新客户。

### **6. 精心设计服务的标题**

标题对你服务的成功销售有著很大的影响。毕竟寻找服务主要关注的就是标题，确保标题起得简洁，有吸引力，让人看了第一个就想买你的服务，关键字是另一个重要因素。合适的关键词能提高曝光率，更容易在潜在的客户搜索的时候找到你的服务。

### **7. 漂亮的视觉效果介绍**

现在是读图时代，图片毕竟是第一眼注意的地方，所以一个漂亮的图片能够提升客户购买你的服务的意愿，如果可以的话，你也可以上传一段视频，更直观的介绍一下自己的服务，可以更加提高销售率

### **8. 尽快获得更多销售**

在Fiverr.com卖家被分配各种不同的水平，包括：新卖家，1级卖家，2级卖家，评价最高的卖家，不同的等级有不一样的服务，例如，新卖家只允许发布7个有效服务，并且只能推出最多$325定制优惠。而第一级卖家允许发布15个有效的发布，可以推出高达$1500定制优惠。

如果你真的想通过Fiverr赚取第一桶金的话，那你需要尽快完成大量销售。通过完成订单，取得不错的销售量，获得更高评价，订单完成越快，升级也会越快，然后获取更好的服务，提高自己服务的排名，接著更加促进销售，形成良性循环。

### **9. 服务第一，价格次之**

对于Fiverr 新手来说，你可以参考成功者的定价方式，但是请先不要像他们一样设定那么高价。新手的任务是要曝光，以服务满意度为优先考量，价格不妨先设低一些( USD $5 )，当你累积了约10~15 笔订单后再慢慢调高。这也是为何你常常可以看到Fiverr 上有很多低价服务，但服务品质却非常好的卖家。

### **10. 回覆迅速**

在手机下载Fiverr app并开启通知，当有买主找上门时就能迅速回覆，这对Fiverr 的演算法是有帮助的，也能将你的Gig 推到更前面。

### **11. 快速做完案子传回**

有些服务其实只要花几分钟就能轻松搞定，快速做完案子，在约定的时间内完成，会给买主留下好印象，让他们愿意给你好的评价。

### **12. 可以的话，提供额外Bonus**

买主的评价对于Gig 排名十分重要，除了快速完成案子以外，你如果能够提供额外的Bonus 给买主，不难想像买主都喜欢花小钱购买物超所值的服务，品质没问题的话，评价一定能够非常好。
