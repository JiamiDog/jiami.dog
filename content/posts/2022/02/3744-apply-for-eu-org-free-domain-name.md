# 申请 eu.org 免费域名

> 本文同步自 [jiami.dog 官方原文](https://jiami.dog/3744.html)，以官网版本为准。

## 准备材料

一个邮箱（最好是 gmail、outlook 之类的常用邮箱）

## 申请流程

打开注册页面 https://nic.eu.org/arf/en/login/ ，点击 Register

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/bfa92db71960f03b7f424a0ad7a3c375.png?ssl=1)

填入个人信息，输入邮箱密码，同意协议，点击 Create

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/3da333d67ba748078254d15c9028bf24.png?ssl=1)

成功创建账号

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/1ce490a919b9b415d78f375cb3b0c66e.png?ssl=1)

在你的邮箱应该会有类似这样的邮件，点击里面的链接激活账号

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/9e808d085fb24e7c3bb7496d397dadb6.png?ssl=1)

输入你在 eu.org 的用户代码（类似于：什么什么 – Free），输入密码，点击 Login 登录

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/7b62912dd2366a10734d87a788dec117.png?ssl=1)

点击 New Domain 创建[域名](https://jiami.dog/tag/domain-names "域名")

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/2e35289ebeafead80cb10788015600e4.png?ssl=1)

输入待申请的域名，输入 dns 记录，点击 Submit

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/36ed0e9e7604cfaa9e555089c195d7b9.png?ssl=1)

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/10d3ea99c52d831a3a1b1c37f0a4b88d.png?ssl=1)

## 域名添加到 CF 的小提示

登录 CF 账号，进入已有的域名，复制下方的两个 dns 服务器即可

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/2ae575516e109c42bcd9de7877a5010f.png?ssl=1)

出现 Error 时，请点击浏览器的返回按钮回到注册页面

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/cafc165f9b0ea4ed9e32daae4db0a3ac.png?ssl=1)

选择第一项 server names，点击 Submit

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/ffcc3e8990ca31769980e3a13997ee04.png?ssl=1)

等待审核通过

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/abc275fa6b6083146ff50b8324a85128.png?ssl=1)

审核通过之后，你的面板上应会有审核好的域名

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/93670c231a30dee4042452638c418f48.png?ssl=1)

点击需要管理的域名

点击 Nameservers

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/ac6ce419a5c16ca9a3b89b830e0bfcae.png?ssl=1)

检查自己的 dns 是否设置正确

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/9dabeb9290e4b6c1181818b7ecdd830a.png?ssl=1)

打开 CF，新增网页

输入域名，点击 Add site

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/675642022bc826809a83f8d6861fa128.png?ssl=1)

选择套餐，点击 Continue

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/c7cfe666256b2504fe9ef35f27f5ce48.png?ssl=1)

设置 dns 解析，点击 Continue

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/31939c2a143d0e211ceb610e2bc80445.png?ssl=1)

添加完成

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/c9bb1e619498396f7533e20644e5ce61.png?ssl=1)

## 问题

1. 为什么我在中国大陆地区无法使用 eu.org 域名？

因为不可描述的原因，eu.org 域名在国内是被强行 http 重置的状态，只需要使用 https 即可

2. 为什么我无法在 CF 添加域名，提示域名未注册

多按几次 Add site 按钮即可或者多等待一段时间

3. 为什么提交了注册好久还没有消息？

多等待一段时间再看吧，手动审核的，一个月内都正常

4. 提示 24error，无法解析 cloudflare 的 ns 记录？

先在 TopDN 注册，把你的域名解析到 TopDN。

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/435f4671385d2b853892c8c656a1601c.jpg?ssl=1)

回到 eu.org 域名注册页面，在 Nameserver 按照如下图填写 TopDN 的 ns 记录，选择第一项 servername，点击 submit。

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/2e55c8063992f4ee0a622b4604667699.jpg?ssl=1)

看到这个 done 就是已经提交申请，需要等待一段时间（短则几小时，长则几个月）等待审核通过，通过或者不通过的情况，官方都会发邮件给你，注意查收邮件。

![](https://i0.wp.com/jiami.dog/wp-content/uploads/2022/02/abc275fa6b6083146ff50b8324a85128.png?ssl=1)
